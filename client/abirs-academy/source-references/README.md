# Source-reference archive

This directory records public pages consulted while building Abir's Academy.

No reuse licence was found on Maths Links during the 15 August 2026 review. For that reason, this project does **not** mirror or redistribute its page copy, worksheets, PDFs, images, logos, scripts, or embedded third-party materials. It links to a small number of useful public pages on the original website, clearly credits the source, and uses original interface copy and design.

The `links.json` file is suitable for inclusion in the R2 source archive. It preserves provenance without copying protected material.
