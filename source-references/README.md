# Source-reference archive

This directory records public pages consulted while building Abir's Academy and preserves the provenance of catalogue entries.

The source-reference files are not proof of a reuse licence. Before any worksheet or solution is uploaded to R2 or published through the site, confirm that Abir's Academy owns it or has direct permission or a licence that allows redistribution. Linking to a public page does not by itself grant redistribution rights.

`links.json` and `deep_links.json` are reference manifests only. Keep credentials, deployment tokens, private notes and copied page content out of this directory.
